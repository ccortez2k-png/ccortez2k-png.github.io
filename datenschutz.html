Datenschutzhinweis – Claude To-dos

Claude To-dos ist eine private Anwendung, die ausschliesslich vom Inhaber dieses GitHub-Kontos für sein eigenes Google-Konto genutzt wird.

  • Die Anwendung liest und schreibt Google Aufgaben und liest Google-Kalender-Termine des angemeldeten Kontos.
  • Die Daten werden nur auf dem eigenen Computer des Inhabers verarbeitet und nicht an Dritte weitergegeben, verkauft oder für Werbung genutzt.
  • Es werden keine Daten anderer Personen erhoben.
  • Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.

Die Nutzung von Google-Daten erfolgt gemäss der Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
